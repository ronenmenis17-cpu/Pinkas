# פנקס הכסף

אפליקציה אישית למעקב פיננסי: הוצאות קבועות ומשתנות, חריגות, ייבוא פירוט אשראי (אקסל או PDF), השקעות והיסטוריית הון.

- עובדת גם בלי אינטרנט, ואפשר להוסיף אותה למסך הבית בטלפון.
- כל הנתונים נשמרים רק במכשיר. המאגר הזה מכיל רק את הקוד, בלי שום נתון אישי.
